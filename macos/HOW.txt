RIZALBOT Mac — Terminal → Xcode

Paste in Terminal:

  curl -fsSL https://raw.githubusercontent.com/rizalward/Rbot/main/link-xcode.sh | bash

or:

  git clone https://github.com/rizalward/Rbot.git ~/Desktop/RIZALBOT
  chmod +x ~/Desktop/RIZALBOT/link-xcode.sh
  ~/Desktop/RIZALBOT/link-xcode.sh

Then in Xcode: scheme YaAimMac → My Mac → Team → Run.
